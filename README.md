# F1 Driver Cards
A React web application that displays Formula 1 driver cards with interactive features such as filtering, sorting, card flipping, and favoriting. This project was created using my interest in Formula 1 to strengthen my understanding of React fundamentals, component-based architecture, and state management.

## Features
- Interactive driver cards
- Card flip animation
- Favorite driver selection
- Sorting and filtering
- Responsive layout

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/bailey-samonte/F1-DriverCards.git
   ```
2. Navigate to the project directory:
   ```bash
   cd F1-DriverCards
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal (typically `http://localhost:5173`) to view the application.
